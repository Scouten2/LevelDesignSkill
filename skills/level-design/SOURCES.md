# Sources

Every source the level-design skill cites, grouped by topic. One line per source: **status · date checked** — name — URL — the rule it supports → files that use it. Reference files cite briefly (author, work, year); URLs live only here.

**Status legend.** **Verified** = the page, paper or file was read in full (or the relevant section). **Partially verified** = known only from a search extract, abstract, table of contents, a secondary report of someone else's statement, or a genre case-study source seen only as a search summary. **Unverified** = could not be reached, or the quoted text was not found; do not quote it as fact. **Contested** = sources disagree. All entries were checked in 2026-10. Rules with no source behind their numbers are tagged **[convention]** in the reference files and do not appear here.

**How to use.** Before quoting a source, check its status. Only Verified sources may be quoted word for word; Partially verified ones are paraphrased with "reportedly" or "according to"; Unverified ones are not cited as fact. Research-strength wording rules for fun claims are in `references/fun-checks.md`.
